# Provider marks

The marks the Model Selector shows beside a model, bundled so the Client never fetches one at
runtime. A model whose provider has no file here is shown by its text alone.

| File            | Provider  |
| --------------- | --------- |
| `anthropic.svg` | Anthropic |
| `google.svg`    | Google    |
| `openai.svg`    | OpenAI    |
| `opencode.svg`  | OpenCode  |
